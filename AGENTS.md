# Website maintenance instructions

Before changing this website, read `SITE_MAINTENANCE.md`.

For every completed website change:

1. Keep the GitHub repository `linsongwei2023-alt/Hibachi-by-lin` as the source of truth.
2. Commit all intended source changes with a clear description and timestamp preserved by Git.
3. Add a short entry to `SITE_CHANGELOG.md` with the UTC date, what changed, and the commit SHA when known.
4. Verify the production deployment and the affected public pages.
5. Never commit passwords, API keys, customer data, payment data, or other secrets.
6. When ChatGPT Library access is available, create a dated portable ZIP snapshot after the work is complete.

Do not rely on chat history as the only record of the project.
